METHOD NOTE

Four activity categories

A simple, repeatable coding scheme makes qualitative program descriptions comparable.

Breeding / care — conservation or insurance breeding, managed rearing.

Release / return — reintroduction, release or wildlife rehabilitation.

Habitat — direct habitat protection, restoration or recovery.

Research — field science, monitoring or specialised animal research.

Scope: 13 examples chosen for teaching and comparison. The activity coding is interpretive and based on the public source material.

Method and caveats

Sample: six zoo/sanctuary sites and 13 selected examples found in public conservation publications. The sample is purposive, not statistically representative of Australia's zoological institutions.

Source coding: binary labels were assigned only when the available public descriptions supported the activity. Each program contains a link to its corresponding source in programs.csv. Counts of examples/mentions should never be interpreted as total zoo activities or success metrics.

Release outcomes: counts use the sources' stated dates and may mean cumulative releases or minimum counts. Releases of eggs are excluded from the comparison of individual animals.

Mapping: site coordinates are approximate. A simplified Australian coastline is stored locally as GeoJSON; it is an overview outline, not an administrative boundary dataset.

Tools: Vega-Lite 5, Vega 5, Vega-Embed 6, HTML, CSS and JavaScript. All eight Vega-Lite specifications are available in js/specs/; extracted input tables are in data/. Data accessed October 2026.
